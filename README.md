# 晏奚的庄园

一个中文像素风慢生活种田游戏。与晏咪、奚咪一起探索竹林、草原、江南水乡、隐雾之林和沙漠，在每张 64×64 网格地图上播种、浇水、收获、照料动物与装饰小院。每张地图有可以进入、休息和换装的小屋，没有强制任务、作物枯萎或动物死亡。

使用 React 19、TypeScript、TanStack Start、Vite、CSS、手绘 SVG 和 Lucide 图标。浏览器 localStorage 保存离线副本，Service Worker 缓存页面及资源，联网时通过 Netlify Functions 和 Netlify Database（Drizzle）备份进度。平台自动部署数据库迁移。首次联网完整载入后支持离线游玩；浏览器须允许站点存储。设置中可生成、复制、验证并导入 FIELD1 储存码，导入将替换当前进度。

## 本地运行

安装 Node.js 22.13+ 或 24，运行 `pnpm install`，再运行 `netlify dev --port 8889`。访问终端显示的本地地址。Netlify 环境提供数据库连接，纯前端玩法即使备份服务不可用仍可继续。生产构建由 Netlify 自动处理。

## 玩法

数字键 1–5 切换移动、播种、浇水、收获和装饰；WASD 或方向键移动。点击地图使用工具，点击动物喂食。作物仅在浇水后开始生长，休息至次日会成熟。背包「收获」可以出售果实，杂货铺提供种子和动物。每 60 经验提升一级，解锁作物、装饰与小屋外观。切换地图共享经验、宋元通宝与背包，但各自保留田地、动物和装饰。

暂停阻止操作并冻结界面计时显示；作物仍按现实时间生长。存档导入采用严格结构校验，无法导入未知版本或缺损数据。建议定期导出储存码，浏览器清理站点数据会清除本机进度。

草原以草和花卉为主，没有树木；江南水乡有雷峰塔、沿河街屋、石桥与荷花，水面有动态波纹。隐雾之林分布着灰白树木、少量兵器、一口朱红大棺材与薄雾，偶尔出现的红衣女鬼会将角色击退，另一位伙伴会挡在身前；不会死亡，也不扣体力、物品或进度。

伙伴会绕过建筑跟随角色，待机时跳跃、翻滚，靠近后会静静贴贴或亲亲，不再翻滚；也会随机各后退一步，在中间摆上酒壶对饮。左右移动时角色会转身，尾巴持续摇晃。背包装饰新增宋式茶案、圈椅、山水屏风、琴案与青瓷花瓶，以及月饼、包子、馒头；点心落地后会吸引伙伴绕过建筑前来，停留进食后消失。晏咪的自动气泡是省略号，奚咪的是爱心。购买种子、动物或装饰，以及升级、解锁和换小屋外观时，伙伴会作出回应。暂停和打开弹窗会暂停场景行为，系统减少动态效果设置也会生效。

装饰目录采用追加 ID 扩展，保留原 v1 储存码与 ID 0–3 的显示含义；旧存档无需转换。新增家具和未吃掉的点心与各地图装饰一起保存，吃掉点心后同步移除本地镜像及联网备份中的对应物品，继续使用严格存档校验。数据库 JSON 存档列不变，无需修改迁移。

家具不再受等级限制，选择后可直接放在空地上。小屋中央有篝火和中式帐幔炕床，提供窗下、左侧、右侧、门边四个陈设位置；可购买宋式茶案、圈椅、青瓷花瓶、山水屏风、琴案和灯笼，每件 15 宋元通宝，收回返还 10 宋元通宝。屋内陈设按地图保存，通过新增的 v1 默认字段兼容旧存档；旧存档自动获得四个空位，现有数据库 JSON 列与迁移不变。

山野手记保留了镜头跟随的 64×64 地图、全图总览、六个随机主题地区与34个采集点。原有地图种子和采集点位置保持稳定，点击采集点即可获得材料，统一放入「收获」栏出售，休息到次日后采集点恢复。

钓鱼直接点击池边的小鱼标记，标记缩小并移除了遮挡人物的牌子。点击后消耗 2 体力并等候五秒，垂钓进度、暂停及钓获提示统一在地图右上角显示，可点击收竿。暂停、弹窗和后台页面停止等候，移动或切换地图会收竿。钓获不会自动打开背包，鲫鱼、鲤鱼、鲈鱼与采集材料都在「收获」栏，与作物一起管理。「出售全部」会出售全部作物、鱼和材料；鱼与材料也可按种类出售，鱼可以放到身边空地喂伙伴。右上角「收获」按钮可以手动跳转到收获栏。

地牢入口、事件探索、工坊、武器制作和角色装备显示已删除。旧存档的历史装备与地牢字段仅为兼容保留，不再参与任何玩法。鱼、采集与庄园进度继续通过严格存档校验、浏览器镜像及 Netlify Database 备份保存，数据库表结构和迁移不变。
